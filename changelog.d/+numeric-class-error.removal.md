**Breaking:** two table columns are now numbers. `tables/variants.tsv` › `class_error_rate` and `tables/novel_orfs.tsv` › `class_fdr` held a number or the word `unestimated`; they now hold a number, or `NA` when the value is not estimated, and such a row carries a flag: `class_error_unestimated` (new, Variants vocabulary) or `class_fdr_unestimated` (as before). A rate of exactly 0 or 1 stays a number. In `variants.vcf` the `CLASS_ERR` INFO value of an unestimated allele is `.`. Scripts that tested the cell for the word `unestimated` must test for `NA` (or the flag) instead. `gippa report` and `gippa compare` still read 1.0 output folders: an `unestimated` cell reads as NA and the row gets the flag. See "Changes in 1.1" on the outputs page.
