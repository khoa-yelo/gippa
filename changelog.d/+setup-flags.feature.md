`gippa setup` has two explicit flags. `--accept-download-plan` skips the confirmation of the download plan and accepts no licence terms. `--install-uniop-from-git` fetches UniOP from its authors' GitHub repository at the pinned commit, checks its sha256 and builds it locally; passing it accepts the UniOP terms (UniOP has no licence file). `--yes`, `--uniop` and `--accept-uniop-terms` still work but are deprecated and hidden from `--help`: each prints a warning that names its replacement. The "terms not accepted" message and the preflight hint now name `--install-uniop-from-git`.
