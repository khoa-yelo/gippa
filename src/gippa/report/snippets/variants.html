A peptide that differs from the annotated protein at a site supports an ALT residue there, and a call's confidence grows with the number of supporting peptides. For de novo peptides, each class of change (its type, and whether it is mass-equivalent) gets an error rate: among de novo reads whose spectrum a database search also identifies confidently, the share where the two peptides disagree. Each rate comes with its count. It is informative only when the reference search could return the variant peptide; a rate of 1 from a search against the reference proteome means not measured, not that every ALT is false.
