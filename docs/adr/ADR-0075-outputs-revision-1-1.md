# ADR-0075: The 1.1 outputs revision, including breaking table-column changes in a minor release
- Status: accepted-by-khoa (2026-11-04, in session: scope "Everything"; columns "1.1, clean break";
  OUT layout "Move + README (Recommended)"; plot style "Accept proposals (Recommended)")
- Date: 2026-11-04
- Spec sections: §9.2 (Versioning: "breaking column changes only in major versions"), §9.3, §10;
  `docs/specs/M12-04-outputs-revision.md`
- Needs Khoa: yes (a spec rule is set aside for one release; interface, layout and style change)

Waives §9.2 Versioning for 1.1.0 only

## Context
Khoa asked for the final plots, tables and report to be updated in 1.1. A review of real runs
(the 200 kb Nissle example on routes A–C and a full K-12 run) found 39 items, 14 of them defects:
summary cards that ignore the input type ("0 peptides placed of 0 input" on a proteins-only run),
no headline stating the tier, degenerate plots on small runs, a locus palette whose mid-range
looks undetected, full-precision numbers against the `%.6g` rule, and inconsistent column names
across tables (`ostir_tir` vs `tir_ostir`, `mw` vs the §9.2 example `mw_da`).

§9.2 allows breaking column changes only in a major version. GIPPA 1.0.0 was released on
2026-11-03; its user base is small and new, and every renamed column brings the tables closer
to §9.2's own naming rules.

## Decision
1. **Scope.** All 39 review items ship in 1.1.0.
2. **Columns: a clean break in 1.1.0, no aliases.**
   - `genes.tsv` is reordered into groups: identity → detection → abundance → function →
     context → features → flags.
   - Names are aligned across tables (for example `ostir_tir` → `tir_ostir`, `mw` → `mw_da`,
     `peptide_len` → `peptide_len_aa`, `promoter_between` → `promoter_score_between`, and one
     name per `class`/`uniop_class` and `flags`/`flag` pair). M12-04 fixes the full list.
   - `class_error_rate` and `class_fdr` become numeric; an unestimated value is `NA` plus a flag.
   - `OUTPUT_SCHEMA_VERSION` increases, the changelog carries a breaking fragment with an
     old → new table, and `docs/reference/tables.md` gets a migration section.
   - The §9.2 rule stands again from 1.1.0: further breaking column changes wait for 2.0.
3. **Layout.** About 40 intermediate files move from the top of `OUT/` to `OUT/intermediate/`.
   A new `OUT/README.txt` explains every folder. Published result paths do not change.
4. **Plot style** (a reviewed change after the M9 approval, §10.1):
   - undetected genes in locus plots are white with a grey outline and hatch;
   - SHAP and partial-dependence panels are hidden when cross-validated R² ≤ 0 or its CI
     includes 0;
   - plot titles use the TU-block null for Moran's I and name it;
   - the V03 index image is dropped; the index stays as a TSV and a report table.
5. **Baselines.** Snapshot baselines regenerated by these PRs need Khoa's approval, PR by PR.

## Evidence (before → after: metrics, tests, simulations)
- Review: `local/handoff/outputs_review_1_1.md` (lead's handoff area), runs Slurm 1931277,
  1931828, 1931445 and the K-12 validation run.
- After: the M12-04 acceptance tests, regenerated goldens and snapshots, and a fresh example run
  of every route.

## Consequences
- Scripts that read 1.0 tables by column name or position break on 1.1 tables. The changelog
  and the tables reference say so first, with the rename table.
- `gippa compare` and `gippa report` on a 1.0 output directory: M12-04 decides whether they read
  it (old names mapped) or refuse with a clear message.
- Every golden table and most snapshot baselines change in 1.1.
